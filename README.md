# Календарь — план по дням

Файл — твой рабочий стол: открываешь, видишь сегодняшний день, делаешь, ставишь галочку.
Детализация: Фаза 0 расписана по дням полностью. Следующие фазы детализируются по дням на контрольной предыдущей (с учётом фактического темпа).

**Правила календаря**
- Слоты двигать можно (вечер ↔ обед на работе), блоки терять нельзя: каждый блок недели должен быть закрыт.
- День пропал — не догоняем всё разом в следующий, сдвигаем на буфер воскресенья. Буфер кончился — говорим, перестраиваем.
- Время каждого дня — целевое. Ушло больше на 50% — стоп, отмечаешь в NOTES «застрял на …», идём дальше или приносишь на сессию.
